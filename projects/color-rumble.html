Color Rumble

PC · Android
Multiplayer vs AI 2D Turn-Based Fighting
My Role in Project
  • Worked on a 2D turn-based fighting game in Unity using Photon Fusion, where two players each bring a team of 3 characters into a match.
  • Implemented the turn system — players pick an action within a timer, then swaps, defends and abilities are resolved in order.
  • Implemented the color matchup rules that decide which ability goes first, along with chain actions for the player who wins the matchup.
  • Built character abilities and status effects, with character and ability data stored in ScriptableObjects.
  • Added game modes including Quick Match, Rank Match, VS AI, Survival and Arcade, with an Elo-style rating for ranked games.
  • Created an AI opponent that picks moves using configurable ability weights.
  • Added character collection and upgrades, stasis pods, daily rewards and daily missions, using Unity Cloud Save and Cloud Code.
  • Integrated a shop with in-app purchases and ads through LevelPlay.
